# Fourmizzz — Skin perso

Userscript cosmétique pour Fourmizzz. Les sources sont découpées dans `src/` (JS par fonction, CSS par page) et les images
sont dans `assets/`. `node build.js` assemble le tout en `dist/fourmizzz-skin.user.js`, à installer dans Tampermonkey
ou Violentmonkey. Règles du projet : voir [CLAUDE.md](CLAUDE.md).
